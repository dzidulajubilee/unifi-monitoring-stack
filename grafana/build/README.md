# Dashboard generators

The Grafana dashboards in `../provisioning/dashboards/` are generated by the Python files here,
except `unifi-firewall.json`, which is edited by hand.

| Dashboard | Generator |
|---|---|
| UniFi Sites | `sites.py` |
| UniFi Gateway | `gateway.py` |
| UniFi Access Points | `aps.py` |
| UniFi Clients | `clients.py` |
| UniFi Switches | `switches.py` |
| UniFi PDU | `pdu.py` |
| UniFi Applications (DPI) | `dpi.py` |

To change a dashboard, edit its generator and run it (Python 3, no packages needed):

```bash
python3 grafana/build/gateway.py
python3 grafana/build/check.py http://localhost:9090 unifi-gateway.json   # runs every query
```

Prometheus listens only on the server, so from another machine open a tunnel first:
`ssh -N -L 9090:localhost:9090 you@server`.

`check.py` prints `ok`, `NONE` (no data, fine for hardware you don't have) or `ERR` (a broken query).
Changes made in the Grafana UI are overwritten the next time a generator runs, so copy them into the
generator. `gf.py` holds the shared helpers: panel types, colours (download blue, upload orange) and layout.

Things to know about the UnPoller data:

- On UniFi OS gateways the WAN byte counters barely move; internet traffic comes from
  `unpoller_site_*_rate_bytes{subsystem="wan"}` instead.
- Client traffic is counted from the access point's side: `transmit` is the device's download.
- DPI figures (`unpoller_client_dpi_*`) are rolling last-24-hours totals that rise and fall; never use
  `increase()` or `rate()` on them.
